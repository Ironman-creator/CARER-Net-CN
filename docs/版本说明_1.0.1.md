# v1.0.1 版本说明

发布日期：2026年10月25日。

本版修订说明文档、模型注释及历史材料整理器的说明文本，并新增既有七方案输入对照的表8复核入口、表格转录及传统三库准备后输入的文件校验工具。模型前向运算、参数结构、损失、训练日程、数据划分、随机种子和测试阈值保持不变；原始实验CSV、JSON、日志、协议及模型来源哈希保留原值，没有新增训练或测试。

## 修订内容

- 将模型注释统一为“FN/FP辅助监督的双分支误差精修”。两个输出分支学习无非负约束的残差响应，最终修正为其tanh响应之差。
- 将说明中的写作建议和警告口吻改为实验条件、结果和运行依赖的客观陈述。
- 明确传统三个数据集的历史实验依赖既有静态预处理灰度副本；现有记录未完整保存生成该副本的参数。FIVES使用原生RGB，按数据准备文档整理。
- 分开说明逐图三种子均值后的图像bootstrap与种子×图像交叉bootstrap，详见[结构分析阅读说明](结构分析阅读说明.md)。
- 保留七种颜色对照，包括表现接近Core的1×1 RGB投影；两者Dice差值区间跨零，结果与原统计一致。

## 版本与来源

v1.0.0中文代码的公开Git提交为 `907cd98c68119b2ad44fecba508d3d6fb892f988`。原来源标识与清单哈希见[原始来源](原始来源_1.0.0.json)。本版两个组件引擎的 `package_manifest.json` 校验当前文件，并保留原清单哈希；整个仓库由根目录 `RELEASE_MANIFEST.json` 校验。

固定结构统计源 `analysis/structure_metrics.py` 及两个组件 `frozen_base/structure_metrics.py` 保持原始字节与哈希，以对应历史 `analysis_manifest.json`。其统计方法与当前论文的对应关系在阅读说明中列明。

组件新运行使用新的输出目录，避免与v1.0.0的预检和封存记录混用；已有实验数值继续由 `component_ablation/analyze_published.py` 独立复算。英文论文仓库独立维护，本版仅更新中文仓库。

## 验证

对原有训练、模型和统计实现进行运行AST比较：剥离模块、类和函数docstring，并单独识别材料整理器中的说明字符串。除说明文本外，原实现的执行结构保持一致。新增复核工具独立验证，六项公开CPU单元测试及发布文件完整性检查的结果记录在根目录 `REPRODUCTION_CHECKS.json`。
