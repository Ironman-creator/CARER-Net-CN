# v1.0.2 版本说明

发布日期：2026年10月26日。

本版将 [Gitee](https://gitee.com/chen-zijian0829/carer-net-cn) 设为中文代码主仓库，保留 [GitHub 中文镜像](https://github.com/Ironman-creator/CARER-Net-CN)，并更新首页的下载方法及 `CITATION.cff` 中的引用入口。中文代码从 Gitee 维护，由维护者向 GitHub 中文镜像单向同步。

## 版本基准与文件范围

本版以 v1.0.1 公开提交 `e0eb193222ec5ddbeb638265ac4fe6a92954b838` 为基准。该版发布清单的 SHA-256 为 `3d13ee77a41b4ecb469456935266df32781bee9e9a1e410161f8900b5769f7f6`。

本次仅修改首页、引用信息及发布清单，并新增本版本说明。原有 Python 实现、训练日程、模型参数结构、数据划分、实验数值、统计源及封存记录保持原字节；许可证仍为 MIT。英文论文仓库独立维护。

根目录 `RELEASE_MANIFEST.json` 校验本版发布文件的字节数及 SHA-256，并保留 v1.0.1 的提交与清单哈希作为来源记录。运行 `python scripts/verify_release.py` 可核对下载文件是否与本版清单一致。

## 验证记录

`REPRODUCTION_CHECKS.json` 仍是 2026年10月25日 v1.0.1 的历史复核记录；其日期、范围及结论按原值保留。本次仓库入口调整不产生新的训练或测试结果。
