# 结构分析与历史来源说明

## 论文表格对应的统计方法

表3、表5及表8的区域指标先对同一图像的三个种子结果取平均，再进行10,000次图像级配对bootstrap，报告95%置信区间。表8沿用历史七方案的未校正区间。

表4及图3从种子×图像的配置间配对差值矩阵出发，分别对训练种子与测试图像有放回抽样，进行10,000次交叉配对bootstrap。Core与公平对照对应 `analysis_role=exploratory_pointwise`、`ci_level=0.95`，即探索性95%区间。配置间保持相同的种子和图像索引。

历史结构分析还保存Refine与公平对照的预设主终点：总体Dice和clDice采用97.5%区间。这些条目与当前表4的Core比较属于不同分析对象；字段筛选见[实验结果索引](实验结果索引.md)。

表7的组件比较为Core−无tanh与Core−随机输出初始化，包含Dice、细血管中心线召回两个指标，共四项比较。使用10,000次交叉配对bootstrap，同时报告95%区间及Bonferroni调整后的98.75%区间。

## 结果的解释

- 病种与质量标签分布存在重叠，质量分层及病种调整后的交互属于探索性关联分析。
- 原发布记录缺少患者标识，结构比较以图像为单位，未实施双眼的患者聚类分析。
- FIVES此前已用于方法开发与结果查看；后续组件分析使用既有测试集，按其后验分析身份报告。
- 七方案颜色对照中，Core和1×1 RGB投影的Dice分别为0.898350与0.898092，差值为0.000258，95%图像级区间为[-0.000396, 0.000871]。本次比较未检出明确差异，也未进行等效性检验。
- 仅RGB残差的新增参数为985，完整Core为1,201，该对照同时涉及输入线索与容量变化。

这些条件与各原始数值文件一并保留。阅读本说明可直接对应当前论文、颜色对照及组件消融；重新计算使用各自发布的统计入口。
