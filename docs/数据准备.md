# 数据准备

本仓库不上传眼底照片、人工标注或模型权重。请从数据原始提供方获取，并遵守其使用条件：

- DRIVE：https://drive.grand-challenge.org/
- STARE：https://cecas.clemson.edu/~ahoover/stare/
- CHASE_DB1：从数据论文配套的原始提供方获取图像与血管标注，并核对所用观察者版本。
- FIVES：https://doi.org/10.6084/m9.figshare.19688169.v1

## 文件结构

```text
data/
  DRIVE/
    train_images/  train_masks/  test_images/  test_masks/
  STARE/
    train_images/  train_masks/  test_images/  test_masks/
  CHASE/
    train_images/  train_masks/  test_images/  test_masks/
  FIVES/
    train_images/  train_masks/  test_images/  test_masks/
```

程序按 `data_utils.py::sample_key` 配对，不要求图像和标注扩展名相同。固定训练/验证成员保存在 `splits/main/`：DRIVE为16/4，STARE为8/2，CHASE为16/4，FIVES为540/60。测试图像数分别为20、10、8、200。STARE与CHASE采用研究中保存的本地测试划分。

FIVES官方目录可用以下命令整理：

```bash
python prepare_fives.py --source "/path/to/FIVES_official" --data-root data
```

## 传统三库的输入条件

本文DRIVE、STARE及CHASE_DB1实验沿用项目已有gamma预处理灰度副本，读入RGB接口后三个通道相同；FIVES保留原生RGB。适配器使用PIL转换的灰度旁路，并在线应用记录的随机增强。

精确重跑DRIVE、STARE与CHASE的历史实验，以相同的静态预处理灰度副本为输入依赖。现有记录未完整保留生成这些副本的全部参数，仓库也未提供从官方彩色原图精确重建副本的独立脚本；获取对应副本及准备流程可联系通讯作者。使用官方彩色原图或其他预处理方案时，应单独记录输入条件并保存新实验结果。已发布的逐图记录可直接用于历史数值核对；FIVES的原生RGB准备流程见上文。

三库准备后输入共88幅图像和88幅标注，文件身份列于[传统三库输入文件校验](传统三库输入文件校验.csv)，来源核对见[传统输入来源说明](传统输入来源说明.md)。取得相应副本后，可按原数据许可使用，并在仓库根目录执行下列命令核对原始字节；程序只读取文件，不转码或重做预处理：

```bash
python scripts/verify_prepared_inputs.py --data-root data
```

图像缩放为512×512，原图双线性插值、标注最近邻插值；强度归一化到[0,1]。视野由未修正的PIL灰度图大于5/255生成，不随颜色适配残差改变。

## 检查划分

固定split中的train/validation是图像键，不是绝对路径。FIVES共600张训练池图像；传统三个数据集的train_images目录应包含该数据集全部train和validation成员。测试目录单独存放，不参与训练或检查点选择。

历史测试图像键可从 `results/carer_3datasets/CARER_3datasets_per_image_dice_deltas.csv` 和 `results/fives_official_test/FIVES_official_test_per_image_dice_deltas.csv` 核对。CHASE测试集8张图像来自4名受试者；原训练/验证划分按图像进行，统计记录未重新构造受试者级划分。
