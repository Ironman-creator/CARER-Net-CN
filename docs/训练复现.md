# 训练与测试

## 安装

```bash
python -m venv .venv
```

Windows PowerShell激活：`.\.venv\Scripts\Activate.ps1`；Linux/macOS激活：`source .venv/bin/activate`。

从PyTorch官方安装渠道安装与显卡驱动匹配的CUDA构建，再执行：

```bash
python -m pip install -r requirements.txt
```

报告环境为PyTorch 2.11.0+cu128。统计复算仅需 `requirements-statistics.txt`，不依赖PyTorch。主模型可在CPU做合成输入自检；512×512完整训练建议使用CUDA设备。

## 主实验计划器

`scripts/run_main_experiments.py` 默认仅打印命令。参数：

- `--datasets FIVES DRIVE STARE CHASE`：CHASE为程序中的名称，论文写作CHASE_DB1。
- `--seeds 42 123 3407`：固定三个种子，也可先选其中一个检查流程。
- `--models gn baseline core refine`：原始GN、30轮灰度继续训练、Core、Refine。
- `--all-baselines`：额外运行U-Net、Attention U-Net、UNet++-GN、R2U-Net-GN及SA-UNet-GN。
- `--data-root`：数据根目录；默认仓库下 `data/`。
- `--output-root`：新实验输出；默认 `artifacts/main_reproduction/`。
- `--phase train/test/all`：仅训练、仅测试或全部。全部模式先完成计划中的训练，再运行测试。
- `--plan-out artifacts/plan.json`：保存全部实际命令。
- `--execute`：确认后实际执行；不传此参数不会训练或测试。

示例：

```bash
python scripts/run_main_experiments.py --datasets FIVES --seeds 42 --plan-out artifacts/fives_seed42.json
python scripts/run_main_experiments.py --datasets FIVES --seeds 42 --execute
```

计划器自动使用 `splits/main/<数据集>/seed_<种子>.json`，不会重新随机划分。需要适配器时先训练该种子的GN主干，再把同一个检查点交给各配置。输出保存在新的目录，不改动历史数值记录。重新执行已有实验前，应使用新的输出目录；原训练程序会拒绝意外覆盖已有日志。

## 日程与损失

基础模型：512×512、batch=1、Adam初始学习率0.0001、BCE/Dice等权、验证soft Dice选点。STARE最多100轮、最少80轮、早停耐心值25；其他三个数据集为50/30/15。

适配器：30轮，前5轮只更新新增模块；随后25轮更新模块、末级解码块及输出层。模块学习率0.0001，末端0.00001，其余主干冻结。轮数匹配灰度对照更新末端完整30轮，不采用5轮模块预热。

Refine的命令参数为 `--base-loss-weight 0.25 --error-loss-weight 0.10`。实现把辅助权重再乘0.5分给FN/FP两个分支，因此对应论文每头0.05。不要把命令中的0.10改成0.05。

公平主对照使用 `train_carer_ablation.py`。`train_carer_paired.py` 保留为历史实现及辅助函数依赖，其旧standalone对照只执行25个末端更新轮，不能代替论文的30轮公平对照。

## 评价和扩展实验

测试阈值固定为0.5，使用 `--fov derived`，不在测试集搜索阈值。GN及比较模型输入为 `grayscale`，Core/Refine为 `gray_rgb`。

- 外部验证：FIVES训练权重直接用于其他三库，沿用固定阈值，不在目标库微调。`test.py --dataset <目标库> --checkpoint <FIVES权重>` 可运行该评价；记录其为迁移结果而非目标库训练结果。
- 扰动：`evaluate_robustness.py --help`。
- 校准：`analyze_probability_calibration.py --help`。
- 结构：`python analysis/structure_metrics.py --help`；需预测掩膜、FIVES官方原图和质量元数据。
- 效率：`benchmark_jiim_models.py --help`；报告中的RTX 4070结果为20次预热后100次前向计时，不与GTX 1650组件训练耗时混用。

模型训练、数据顺序和确定性设置均保留在原实现中。跨显卡、CUDA、PyTorch版本重训时，应同时比较划分、配置和指标，不以检查点文件字节完全相同作为跨环境训练一致性的唯一标准。
